# Siderkit Break

**श्वास घेण्यासाठी थोडी जागा.**

Windows, macOS आणि Linux साठी शांत, स्थानिक-प्रथम फोकस टाइमर. तो तुमची लय टिकवतो, वाटेत येत नाही आणि उठून दूर पाहण्याची आठवण करून देतो.

## प्रमुख वैशिष्ट्ये

- **तुमच्या जुळणारी लय.** फोकस, छोटा विराम आणि लांब विराम यांचे चक्र, थांबवा, पुन्हा सुरू, वगळा आणि रीसेटसह.
- **वाटेत येत नाही.** नेहमी वर राहणारा छोटा काउंटडाउन, जो तुम्ही त्याकडे बोट दाखवेपर्यंत क्लिक पुढे जाऊ देतो.
- **कृती करता येणारे स्मरण.** प्रत्येक टप्प्याच्या शेवटी अ‍ॅपमधील कार्ड, पुढे ढकला, वगळा आणि अंगभूत आवाजासह.
- **डेटा तुमच्याकडेच राहतो.** स्थानिक सत्र इतिहास, स्प्रेडशीट निर्यात, 40 भाषा, थीम आणि जागतिक शॉर्टकट.

## स्रोतातून तयार करा

Node.js 22+, pnpm 12, Rust टूलचेन आणि डेस्कटॉप फ्रेमवर्कसाठी आवश्यक प्लॅटफॉर्म बिल्ड साधने आवश्यक आहेत.

```bash
pnpm install
pnpm check
pnpm tauri build
```

संपूर्ण प्लॅटफॉर्म मॅट्रिक्स आणि बंडल आदेश इंग्रजी README मध्ये आहेत.
