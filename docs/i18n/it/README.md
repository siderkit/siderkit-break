# Siderkit Break

**Un po’ di spazio per respirare.**

Un timer di concentrazione tranquillo e locale per Windows, macOS e Linux. Mantiene il ritmo, resta fuori dai piedi e ti ricorda di alzarti e guardare lontano.

## In evidenza

- **Un ritmo su misura.** Cicli di concentrazione, pausa breve e pausa lunga con pausa, ripresa, salto e reimpostazione.
- **Non ingombra.** Un piccolo conto alla rovescia sempre in primo piano che lascia passare i clic finché non lo punti.
- **Promemoria azionabili.** Schede nell’app a ogni fine fase, con rinvio, salto e un suono integrato.
- **I tuoi dati restano locali.** Cronologia locale, esportazione in foglio di calcolo, 40 lingue, temi e scorciatoie globali.

## Compila dai sorgenti

Node.js 22+, pnpm 12, una toolchain Rust e gli strumenti di compilazione della piattaforma richiesti dal framework desktop.

```bash
pnpm install
pnpm check
pnpm tauri build
```

La matrice completa delle piattaforme e i comandi di pacchettizzazione sono nel README inglese.
