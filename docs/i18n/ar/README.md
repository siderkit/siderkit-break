# Siderkit Break

**مساحة صغيرة للتنفّس.**

مؤقّت تركيز هادئ يعمل محليًا لأنظمة Windows وmacOS وLinux. يحافظ على إيقاعك، لا يزعجك، ويذكّرك بالوقوف والنظر إلى مسافة بعيدة.

## أبرز الميزات

- **إيقاع يناسبك.** دورات تركيز واستراحة قصيرة واستراحة طويلة مع إيقاف مؤقت واستئناف وتخطٍّ وإعادة ضبط.
- **لا يعترض طريقك.** عدّاد تنازلي صغير يبقى في الأعلى ويسمح بالنقر من خلاله حتى تشير إليه.
- **تذكيرات قابلة للتنفيذ.** بطاقات داخل التطبيق عند نهاية كل مرحلة، مع تأجيل وتخطٍّ وصوت مدمج.
- **بياناتك تبقى لديك.** سجل جلسات محلي، تصدير إلى جدول بيانات، 30 لغة، سمات واختصارات عامة.

## البناء من المصدر

يتطلب Node.js 22+ وpnpm 12 وأدوات Rust وأدوات بناء المنصة التي يحتاجها إطار سطح المكتب.

```bash
pnpm install
pnpm check
pnpm tauri build
```

مصفوفة المنصات الكاملة وأوامر الحزم موجودة في README بالإنجليزية.
