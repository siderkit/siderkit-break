# Siderkit Break

**மூச்சு விட கொஞ்சம் இடைவெளி.**

Windows, macOS மற்றும் Linux க்கான அமைதியான, உள்ளூர்-முதன்மை கவன டைமர். உங்கள் தாளத்தைத் தக்கவைத்து, இடையூறு செய்யாமல், எழுந்து தொலைவில் பார்க்க நினைவூட்டுகிறது.

## சிறப்பம்சங்கள்

- **உங்களுக்கு ஏற்ற தாளம்.** கவனம், சிறு இடைவேளை மற்றும் நீண்ட இடைவேளை சுழற்சிகள், இடைநிறுத்தம், தொடர், தவிர் மற்றும் மீட்டமைப்புடன்.
- **இடையூறு செய்யாது.** எப்போதும் மேலே இருக்கும் சிறிய கவுண்டவுன், நீங்கள் சுட்டிக்காட்டும் வரை கிளிக்குகளை கடக்க அனுமதிக்கிறது.
- **செயல்படுத்தக்கூடிய நினைவூட்டல்கள்.** ஒவ்வொரு கட்டத்தின் முடிவிலும் பயன்பாட்டில் அட்டைகள், ஒத்திவை, தவிர் மற்றும் உள்ளமைந்த ஒலியுடன்.
- **தரவு உங்களிடமே இருக்கும்.** உள்ளூர் அமர்வு வரலாறு, விரிதாள் ஏற்றுமதி, 40 மொழிகள், தீம்கள் மற்றும் உலகளாவிய குறுக்குவழிகள்.

## மூலத்திலிருந்து உருவாக்கு

Node.js 22+, pnpm 12, Rust கருவித்தொகுப்பு மற்றும் டெஸ்க்டாப் ஃபிரேம்வொர்க்கிற்குத் தேவையான தளம் கட்டமைப்பு கருவிகள் தேவை.

```bash
pnpm install
pnpm check
pnpm tauri build
```

முழு தள அணி மற்றும் தொகுப்பு கட்டளைகள் ஆங்கில README இல் உள்ளன.
