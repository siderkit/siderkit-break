# Siderkit Break

**Sedikit ruang untuk bernapas.**

Pengingat fokus yang tenang dan mengutamakan data lokal untuk Windows, macOS, dan Linux. Ia menjaga ritme, tidak mengganggu, dan mengingatkan Anda untuk berdiri dan melihat jauh.

## Sorotan

- **Ritme yang pas.** Siklus fokus, istirahat singkat, dan istirahat panjang dengan jeda, lanjutkan, lewati, dan atur ulang.
- **Tidak menghalangi.** Hitungan mundur kecil yang selalu di atas dan meneruskan klik sampai Anda mengarahkannya.
- **Pengingat yang bisa ditindaklanjuti.** Kartu di dalam aplikasi di setiap akhir fase, dengan tunda, lewati, dan suara bawaan.
- **Data tetap milik Anda.** Riwayat sesi lokal, ekspor spreadsheet, 40 bahasa, tema, dan pintasan global.

## Bangun dari sumber

Membutuhkan Node.js 22+, pnpm 12, toolchain Rust, dan alat build platform yang diperlukan framework desktop.

```bash
pnpm install
pnpm check
pnpm tauri build
```

Matriks platform lengkap dan perintah bundel ada di README bahasa Inggris.
