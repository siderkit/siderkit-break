# Siderkit Break

**Немного места, чтобы выдохнуть.**

Спокойный таймер концентрации с приоритетом локальной работы для Windows, macOS и Linux. Он помогает держать ритм, не мешает и напоминает встать и посмотреть вдаль.

## Возможности

- **Подходящий ритм.** Циклы концентрации, короткого и длинного перерыва с паузой, продолжением, пропуском и сбросом.
- **Не мешает.** Небольшой обратный отсчёт всегда сверху; клики проходят сквозь него, пока вы не наведёте курсор.
- **Напоминания с действиями.** Карточки в приложении на каждой границе этапа: отложить, пропустить и встроенный звук.
- **Данные остаются у вас.** Локальная история сеансов, экспорт в таблицу, 30 языков, темы и глобальные горячие клавиши.

## Сборка из исходников

Требуются Node.js 22+, pnpm 12, инструменты Rust и системные средства сборки, необходимые для десктопного фреймворка.

```bash
pnpm install
pnpm check
pnpm tauri build
```

Полный список платформ и команды сборки пакетов см. в английском README.
