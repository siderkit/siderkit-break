# Siderkit Break

**साँस लेने के लिए थोड़ी जगह।**

Windows, macOS और Linux के लिए एक शांत, लोकल-फ़र्स्ट फ़ोकस टाइमर। यह आपकी लय बनाए रखता है, रास्ते में नहीं आता, और उठकर दूर देखने की याद दिलाता है।

## मुख्य विशेषताएँ

- **आपके अनुकूल लय.** फ़ोकस, छोटे ब्रेक और लंबे ब्रेक के चक्र, पॉज़, फिर शुरू, छोड़ें और रीसेट के साथ।
- **रास्ते में नहीं.** एक छोटा काउंटडाउन जो हमेशा ऊपर रहता है और इशारा करने तक क्लिक पास होने देता है।
- **काम करने योग्य रिमाइंडर.** हर चरण के अंत में ऐप के अंदर कार्ड, टालें, छोड़ें और अंतर्निहित ध्वनि के साथ।
- **डेटा आपके पास रहता है.** स्थानीय सत्र इतिहास, स्प्रेडशीट निर्यात, 40 भाषाएँ, थीम और वैश्विक शॉर्टकट।

## सोर्स से बनाएँ

Node.js 22+, pnpm 12, Rust टूलचेन और डेस्कटॉप फ़्रेमवर्क के लिए ज़रूरी प्लेटफ़ॉर्म बिल्ड टूल्स चाहिए।

```bash
pnpm install
pnpm check
pnpm tauri build
```

पूरा प्लेटफ़ॉर्म मैट्रिक्स और बंडल कमांड अंग्रेज़ी README में हैं।
