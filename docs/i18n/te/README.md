# Siderkit Break

**గాలి పీల్చుకోవడానికి కొంచెం సమయం.**

Windows, macOS మరియు Linux కోసం ప్రశాంతమైన, లోకల్-ఫస్ట్ ఫోకస్ టైమర్. ఇది మీ లయను కాపాడుతుంది, అడ్డుపడదు, మరియు నిలబడి దూరంగా చూడమని గుర్తు చేస్తుంది.

## ముఖ్యాంశాలు

- **మీకు సరిపోయే లయ.** ఫోకస్, చిన్న విరామం మరియు పొడవైన విరామ చక్రాలు, పాజ్, కొనసాగించు, దాటవేయి మరియు రీసెట్‌తో.
- **అడ్డుపడదు.** ఎప్పుడూ పైన ఉండే చిన్న కౌంట్‌డౌన్, మీరు సూచించే వరకు క్లిక్‌లను పంపిస్తుంది.
- **పని చేయగల రిమైండర్లు.** ప్రతి దశ ముగింపులో యాప్‌లో కార్డులు, వాయిదా, దాటవేయి మరియు బిల్ట్-ఇన్ శబ్దంతో.
- **డేటా మీ దగ్గరే ఉంటుంది.** లోకల్ సెషన్ చరిత్ర, స్ప్రెడ్‌షీట్ ఎగుమతి, 30 భాషలు, థీమ్‌లు మరియు గ్లోబల్ షార్ట్‌కట్‌లు.

## సోర్స్ నుండి బిల్డ్ చేయండి

Node.js 22+, pnpm 12, Rust టూల్‌చెయిన్ మరియు డెస్క్‌టాప్ ఫ్రేమ్‌వర్క్‌కు అవసరమైన ప్లాట్‌ఫారమ్ బిల్డ్ టూల్స్ అవసరం.

```bash
pnpm install
pnpm check
pnpm tauri build
```

పూర్తి ప్లాట్‌ఫారమ్ మ్యాట్రిక్స్ మరియు బండిల్ కమాండ్‌లు ఇంగ్లీష్ READMEలో ఉన్నాయి.
