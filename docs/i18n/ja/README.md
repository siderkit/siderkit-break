# Siderkit Break

**ひと息つく、小さな余白。**

Windows、macOS、Linux 向けの、静かでローカル優先の集中タイマーです。集中のリズムを保ち、邪魔をせず、立ち上がって遠くを見るべきタイミングを知らせます。

## 主な機能

- **自分に合うリズム.** 集中、短い休憩、長い休憩のサイクル。一時停止、再開、スキップ、リセットに対応します。
- **邪魔をしない.** 常に最前面に表示される小さなカウントダウン。ポインターを合わせるまでクリックを透過します。
- **行動できるリマインダー.** 各フェーズの終わりにアプリ内カードを表示。延期やスキップができ、内蔵の通知音も鳴ります。
- **データはローカルに.** ローカルのセッション履歴、表計算ソフト向けエクスポート、40 言語、テーマ、グローバルショートカット。

## ソースからビルド

Node.js 22+、pnpm 12、Rust ツールチェーン、およびデスクトップフレームワークに必要なビルドツールが必要です。

```bash
pnpm install
pnpm check
pnpm tauri build
```

対応プラットフォームの一覧とバンドル手順は英語 README を参照してください。
