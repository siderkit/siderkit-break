# Siderkit Break

**Un pequeño respiro.**

Un temporizador de concentración tranquilo y local para Windows, macOS y Linux. Mantiene tu ritmo, no te interrumpe y te recuerda levantarte y mirar a lo lejos.

## Aspectos destacados

- **Un ritmo a tu medida.** Ciclos de concentración, descanso corto y descanso largo con pausa, reanudación, salto y reinicio.
- **Sin estorbar.** Una pequeña cuenta atrás siempre visible que deja pasar los clics hasta que la señalas.
- **Recordatorios accionables.** Tarjetas dentro de la app al final de cada fase, con posponer, saltar y un aviso sonoro integrado.
- **Tus datos se quedan contigo.** Historial local, exportación a hoja de cálculo, 30 idiomas, temas y atajos globales.

## Compilar desde el código fuente

Node.js 22+, pnpm 12, una toolchain de Rust y las herramientas de compilación de la plataforma que requiere el framework de escritorio.

```bash
pnpm install
pnpm check
pnpm tauri build
```

La matriz completa de plataformas y los comandos de empaquetado están en el README en inglés.
