# Siderkit Break

**سانس لینے کے لیے تھوڑی جگہ۔**

Windows، macOS اور Linux کے لیے ایک پرسکون، مقامی طور پر چلنے والا فوکس ٹائمر۔ یہ آپ کا ردھم برقرار رکھتا ہے، خلل نہیں ڈالتا، اور کھڑے ہو کر دور دیکھنے کی یاد دلاتا ہے۔

## نمایاں خصوصیات

- **آپ کے مطابق ردھم.** فوکس، مختصر وقفہ اور طویل وقفہ کے چکر، وقفہ، جاری رکھنے، چھوڑنے اور ری سیٹ کے ساتھ۔
- **راستے میں نہیں.** ایک چھوٹا کاؤنٹ ڈاؤن جو ہمیشہ اوپر رہتا ہے اور اشارہ کرنے تک کلکس گزرنے دیتا ہے۔
- **قابل عمل یاد دہانیاں.** ہر مرحلے کے اختتام پر ایپ کے اندر کارڈ، تاخیر، چھوڑنے اور بلٹ اِن آواز کے ساتھ۔
- **ڈیٹا آپ کے پاس رہتا ہے.** مقامی سیشن تاریخ، اسپریڈ شیٹ ایکسپورٹ، 30 زبانیں، تھیمز اور عالمی شارٹ کٹس۔

## سورس سے بنائیں

Node.js 22+، pnpm 12، Rust ٹول چین، اور ڈیسک ٹاپ فریم ورک کے لیے درکار پلیٹ فارم بلڈ ٹولز ضروری ہیں۔

```bash
pnpm install
pnpm check
pnpm tauri build
```

مکمل پلیٹ فارم میٹرکس اور بنڈل کمانڈز انگریزی README میں ہیں۔
