# Siderkit Break

**给呼吸留一点空间。**

一款安静、本地优先的专注计时器，适用于 Windows、macOS 和 Linux。它帮你保持专注节奏，不打扰你，并在该起身远眺时提醒你。

## 功能亮点

- **合适的节奏.** 专注、短休息、长休息循环，支持暂停、继续、跳过和重置。
- **不挡路.** 一个始终置顶的小巧倒计时，鼠标未指向时保持点击穿透。
- **可操作的提醒.** 每个阶段结束时弹出应用内提醒卡片，可延后或跳过，并带有内置提示音。
- **数据留在本地.** 本地会话历史、表格导出、40 种语言、主题和全局快捷键。

## 从源码构建

需要 Node.js 22+、pnpm 12、Rust 工具链，以及桌面框架所需的平台构建工具。

```bash
pnpm install
pnpm check
pnpm tauri build
```

完整平台矩阵和打包命令见英文 README。
