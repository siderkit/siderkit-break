# Siderkit Break

**নিঃশ্বাস নেওয়ার একটু জায়গা।**

Windows, macOS ও Linux-এর জন্য একটি শান্ত, লোকাল-ফার্স্ট ফোকাস টাইমার। এটি আপনার ছন্দ ধরে রাখে, পথে বাধা দেয় না, এবং উঠে দূরে তাকানোর কথা মনে করিয়ে দেয়।

## প্রধান বৈশিষ্ট্য

- **আপনার মতো ছন্দ.** ফোকাস, ছোট বিরতি ও দীর্ঘ বিরতির চক্র, বিরতি, চালিয়ে যাওয়া, এড়িয়ে যাওয়া ও রিসেটসহ।
- **পথে বাধা দেয় না.** একটি ছোট কাউন্টডাউন যা সবসময় উপরে থাকে এবং আপনি ইশারা করার আগে ক্লিক পাস হতে দেয়।
- **কাজে লাগানো যায় এমন রিমাইন্ডার.** প্রতিটি ধাপের শেষে অ্যাপের ভিতরে কার্ড, স্থগিত, এড়িয়ে যাওয়া এবং অন্তর্নির্মিত শব্দসহ।
- **ডেটা আপনার কাছেই থাকে.** স্থানীয় সেশন ইতিহাস, স্প্রেডশিট এক্সপোর্ট, 30 ভাষা, থিম এবং গ্লোবাল শর্টকাট।

## সোর্স থেকে বানান

Node.js 22+, pnpm 12, Rust টুলচেইন এবং ডেস্কটপ ফ্রেমওয়ার্কের প্রয়োজনীয় প্ল্যাটফর্ম বিল্ড টুলস দরকার।

```bash
pnpm install
pnpm check
pnpm tauri build
```

সম্পূর্ণ প্ল্যাটফর্ম ম্যাট্রিক্স ও বান্ডল কমান্ড ইংরেজি README-তে আছে।
