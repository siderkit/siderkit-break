# Siderkit Break

**Un mic răgaz ca să respiri.**

Un cronometru de concentrare calm, cu date locale, pentru Windows, macOS și Linux. Îți păstrează ritmul, nu te deranjează și îți amintește să te ridici și să privești departe.

## Principalele funcții

- **Un ritm potrivit.** Cicluri de concentrare, pauză scurtă și pauză lungă, cu pauză, reluare, sărire și resetare.
- **Nu te încurcă.** Un mic numărător invers mereu deasupra, care lasă clicurile să treacă până îl indici.
- **Reamintiri acționabile.** Carduri în aplicație la fiecare sfârșit de etapă, cu amânare, sărire și un sunet integrat.
- **Datele rămân la tine.** Istoric local al sesiunilor, export în foaie de calcul, 30 de limbi, teme și scurtături globale.

## Compilează din surse

Necesită Node.js 22+, pnpm 12, un toolchain Rust și instrumentele de compilare ale platformei cerute de framework-ul desktop.

```bash
pnpm install
pnpm check
pnpm tauri build
```

Matricea completă a platformelor și comenzile de împachetare sunt în README-ul englez.
