# Siderkit Break

**کمی فضا برای نفس کشیدن.**

یک تایمر تمرکز آرام و محلی برای Windows، macOS و Linux. ریتم شما را حفظ می‌کند، مزاحم نمی‌شود و یادآوری می‌کند که بایستید و به دور نگاه کنید.

## ویژگی‌ها

- **ریتمی که مناسب شماست.** چرخه‌های تمرکز، استراحت کوتاه و استراحت طولانی با توقف، ادامه، رد کردن و بازنشانی.
- **مزاحم نمی‌شود.** شمارش معکوس کوچکی که همیشه بالا می‌ماند و تا وقتی به آن اشاره نکنید کلیک‌ها را عبور می‌دهد.
- **یادآوری‌های قابل اقدام.** کارت‌های درون برنامه در پایان هر مرحله، با به تعویق انداختن، رد کردن و صدای داخلی.
- **داده‌ها پیش شما می‌مانند.** تاریخچه محلی جلسات، خروجی صفحه‌گسترده، 30 زبان، پوسته‌ها و میانبرهای سراسری.

## ساخت از منبع

به Node.js 22+، pnpm 12، ابزار Rust و ابزارهای ساخت پلتفرم که چارچوب دسکتاپ نیاز دارد، نیاز است.

```bash
pnpm install
pnpm check
pnpm tauri build
```

ماتریس کامل پلتفرم‌ها و دستورهای بسته‌بندی در README انگلیسی آمده است.
