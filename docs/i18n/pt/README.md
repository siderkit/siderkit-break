# Siderkit Break

**Um pequeno espaço para respirar.**

Um temporizador de concentração calmo e local para Windows, macOS e Linux. Mantém o seu ritmo, fica fora do caminho e lembra-o de se levantar e olhar para longe.

## Destaques

- **Um ritmo à sua medida.** Ciclos de concentração, pausa curta e pausa longa com pausa, retoma, salto e reinício.
- **Sem atrapalhar.** Uma pequena contagem decrescente sempre visível que deixa passar os cliques até apontar para ela.
- **Lembretes acionáveis.** Cartões na aplicação no fim de cada fase, com adiar, saltar e um som integrado.
- **Os seus dados ficam consigo.** Histórico local, exportação para folha de cálculo, 40 idiomas, temas e atalhos globais.

## Compilar a partir do código-fonte

Node.js 22+, pnpm 12, uma toolchain Rust e as ferramentas de compilação da plataforma exigidas pelo framework de desktop.

```bash
pnpm install
pnpm check
pnpm tauri build
```

A matriz completa de plataformas e os comandos de empacotamento estão no README em inglês.
