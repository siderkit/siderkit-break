# Siderkit Break

**Un peu d’espace pour respirer.**

Un minuteur de concentration calme et local pour Windows, macOS et Linux. Il garde votre rythme, reste discret et vous rappelle de vous lever et de regarder au loin.

## Points forts

- **Un rythme qui vous ressemble.** Cycles de concentration, pause courte et pause longue, avec pause, reprise, passage et réinitialisation.
- **Discret.** Un petit compte à rebours toujours au premier plan, qui laisse passer les clics tant que vous ne le pointez pas.
- **Des rappels actionnables.** Des cartes dans l’application à chaque fin de phase, avec report, passage et une sonnerie intégrée.
- **Vos données restent locales.** Historique local, export tableur, 30 langues, thèmes et raccourcis globaux.

## Compiler depuis les sources

Node.js 22+, pnpm 12, une toolchain Rust et les outils de compilation de la plateforme requis par le framework de bureau.

```bash
pnpm install
pnpm check
pnpm tauri build
```

La matrice complète des plateformes et les commandes de paquetage se trouvent dans le README anglais.
