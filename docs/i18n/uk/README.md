# Siderkit Break

**Трохи місця, щоб видихнути.**

Спокійний таймер концентрації з локальним підходом для Windows, macOS і Linux. Він тримає ритм, не заважає та нагадує встати й подивитися вдалину.

## Можливості

- **Свій ритм.** Цикли концентрації, короткої та довгої перерви з паузою, продовженням, пропуском і скиданням.
- **Не заважає.** Невеликий зворотний відлік завжди зверху; кліки проходять крізь нього, доки ви не наведете курсор.
- **Нагадування з діями.** Картки в застосунку на кожній межі етапу: відкласти, пропустити та вбудований звук.
- **Дані залишаються у вас.** Локальна історія сеансів, експорт у таблицю, 40 мов, теми та глобальні гарячі клавіші.

## Збірка з вихідного коду

Потрібні Node.js 22+, pnpm 12, інструменти Rust і системні засоби збірки для десктопного фреймворку.

```bash
pnpm install
pnpm check
pnpm tauri build
```

Повний перелік платформ і команди пакування див. в англійському README.
