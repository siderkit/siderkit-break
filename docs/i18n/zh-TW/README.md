# Siderkit Break

**留一點空間，好好呼吸。**

一款安靜、本機優先的專注計時器，適用於 Windows、macOS 與 Linux。它幫你維持專注節奏、不打擾你，並在該起身遠眺時提醒你。

## 功能亮點

- **合適的節奏.** 專注、短休息、長休息循環，支援暫停、繼續、跳過與重設。
- **不擋路.** 一個始終置頂的小巧倒數，滑鼠未指向時保持點擊穿透。
- **可操作的提醒.** 每個階段結束時顯示應用程式內提醒卡片，可延後或跳過，並附有內建提示音。
- **資料留在本機.** 本機工作階段紀錄、試算表匯出、30 種語言、主題與全域快速鍵。

## 從原始碼建置

需要 Node.js 22+、pnpm 12、Rust 工具鏈，以及桌面框架所需的平台建置工具。

```bash
pnpm install
pnpm check
pnpm tauri build
```

完整平台矩陣與打包指令請見英文 README。
