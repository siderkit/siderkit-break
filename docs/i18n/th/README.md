# Siderkit Break

**มีพื้นที่ให้หายใจสักนิด**

ตัวจับเวลาโฟกัสที่สงบและเก็บข้อมูลไว้ในเครื่องสำหรับ Windows, macOS และ Linux ช่วยรักษาจังหวะ ไม่รบกวน และเตือนให้ลุกขึ้นมองไกลๆ

## จุดเด่น

- **จังหวะที่เหมาะกับคุณ.** รอบโฟกัส พักสั้น และพักยาว พร้อมหยุดชั่วคราว ทำต่อ ข้าม และรีเซ็ต
- **ไม่รบกวน.** นาฬิกานับถอยหลังเล็กๆ ที่อยู่บนสุดเสมอและปล่อยให้คลิกทะลุได้จนกว่าคุณจะชี้
- **การเตือนที่ลงมือได้.** การ์ดในแอปทุกจุดสิ้นสุดของช่วง พร้อมเลื่อนออกไป ข้าม และเสียงเตือนในตัว
- **ข้อมูลอยู่ในเครื่องคุณ.** ประวัติเซสชันในเครื่อง ส่งออกสเปรดชีต 40 ภาษา ธีม และปุ่มลัดทั่วระบบ

## สร้างจากซอร์สโค้ด

ต้องใช้ Node.js 22+, pnpm 12, Rust toolchain และเครื่องมือ build ของแพลตฟอร์มที่เฟรมเวิร์กเดสก์ท็อปต้องใช้

```bash
pnpm install
pnpm check
pnpm tauri build
```

ดูเมทริกซ์แพลตฟอร์มทั้งหมดและคำสั่งแพ็กเกจใน README ภาษาอังกฤษ
