# Siderkit Break

**Một chút không gian để thở.**

Một bộ hẹn giờ tập trung nhẹ nhàng, ưu tiên dữ liệu cục bộ cho Windows, macOS và Linux. Nó giữ nhịp tập trung, không làm phiền và nhắc bạn đứng dậy nhìn ra xa.

## Điểm nổi bật

- **Nhịp độ phù hợp.** Chu kỳ tập trung, nghỉ ngắn và nghỉ dài với tạm dừng, tiếp tục, bỏ qua và đặt lại.
- **Không làm phiền.** Đồng hồ đếm ngược nhỏ luôn ở trên cùng, cho phép bấm xuyên qua cho đến khi bạn trỏ vào.
- **Nhắc nhở có hành động.** Thẻ trong ứng dụng ở mỗi cuối giai đoạn, có hoãn, bỏ qua và âm thanh tích hợp.
- **Dữ liệu ở lại với bạn.** Lịch sử phiên cục bộ, xuất bảng tính, 40 ngôn ngữ, giao diện và phím tắt toàn cục.

## Build từ mã nguồn

Cần Node.js 22+, pnpm 12, Rust toolchain và các công cụ build nền tảng mà framework desktop yêu cầu.

```bash
pnpm install
pnpm check
pnpm tauri build
```

Ma trận nền tảng đầy đủ và lệnh đóng gói có trong README tiếng Anh.
